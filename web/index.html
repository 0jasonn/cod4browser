The importer reads only localization.txt and main/iw_00.iwd for this milestone. It copies those files into origin-private browser storage, then reopens them through the asynchronous WebAssembly archive reader. A bounded IWI member is validated; when it matches the initial format-1 slice, portable code converts it to RGBA8 and uploads it through a renderer seam. Other valid formats are deferred. Only bounded recovery pixels remain after a supported request completes. Your source folder stays untouched.

You must supply files from a legally owned Call of Duty 4 installation. Game data remains on this device and is never sent to the server.
